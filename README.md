# MediCare Hospital Management System

A simple full-stack web application for managing basic hospital activities such as patients, doctors, appointments, and bills.

## Features

- Patient management
- Doctor management
- Appointment management
- Bill management
- Hospital dashboard
- REST API for backend operations
- MySQL database

## Tech Stack

**Frontend**
- React.js
- CSS
- Vite

**Backend**
- Node.js
- Express.js

**Database**
- MySQL

## How to Run

### 1. Open the project

Open the `medicare-hospital-management` folder in VS Code.

### 2. Start the Backend

In VS Code, click:

**Terminal → New Terminal**

A terminal will open at the bottom.

Run these commands one by one:

```bash
cd backend
npm install
npm start
